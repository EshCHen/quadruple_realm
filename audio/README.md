# audio · 背景音乐放置说明

把音乐文件放进**本文件夹**（与 `index.html` 同级），页面会在**登录 / 访客进入后自动播放**。

## 命名规则（放对名字就能自动识别，任选其一）

| 用途 | 文件名 |
|---|---|
| 通用背景音乐（推荐） | `bgm.mp3` |
| 备用可识别名 | `bgm.m4a` / `bgm.ogg` / `bgm.wav` / `music.mp3` / `theme.mp3` |
| 四域专属（可选，进入该域主题时优先播） | `east.mp3`（东域）/ `west.mp3`（西域）/ `south.mp3`（南域）/ `north.mp3`（北域）/ `magic.mp3`（魔域） |

> 有 `east.mp3` 等域专属文件时，只有对应域被随机选中才会播；没有就回落到 `bgm.mp3`。
> 都没有 = 静默无声，不会报错。

## 格式与体积建议

- **推荐 mp3**（兼容最好；`ogg` iOS 不支持）；
- 码率 128–192kbps，单曲 2–5MB 为宜；
- GitHub 建议单文件 < 50MB、仓库 < 1GB，**不要放无损 wav**。

## 其它

- 播放控制：页面右下角 **♪ 按钮**（开/关 + 音量），偏好记忆在本机 localStorage；
- 登出后自动停止；
- **部署时本文件夹必须一起上传**，否则页面找不到音乐（只是没声音，不会报错）。
