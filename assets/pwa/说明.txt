四分境域 · App 图标（PWA）说明
=========================================

一键导出 PNG
------------
有两种方式，任选其一：

【方式 A · 用自己的图】打开 assets/pwa/resize-icon.html
  → 点击或拖入你自己的图片
  → 选「居中裁成正方形」（App 图标推荐）或「完整保留 + 补边」
  → 点按钮下载 icon-192.png / icon-512.png / icon-1024.png
  → 放进本目录（文件名不要改）即可

【方式 B · 用内置徽记】打开 assets/pwa/make-icon.html
  → 直接点按钮下载同名的三张 PNG
  → 同样放进本目录

两种方式产出的文件名一致，manifest 与 index.html 里的引用都已接好，不用改任何代码。

为什么需要 PNG？
----------------
· 安卓 Chrome：SVG 通常够用，但有 PNG 才能稳定触发「安装应用」提示
· iOS Safari：**不认 SVG**，必须用 PNG，否则主屏图标会显示成截图
· maskable 图标也要求 PNG

所以这两张 PNG 是"能不能像 App 一样装到手机"的关键。

图标设计
--------
深色底 + 四域十字（北/南/西/东四条银灰圆角条）+ 中央中灰菱形（魔域·共治），
菱形中心一个深色圆孔 = 共治枢纽。

整枚**全灰调**：外圈用亮银灰（#d8dce2），中央用中灰（#8d949e），
不使用任何单域的专属色，所以在任何背景、任何尺寸下都不会偏色，也不会
和某一域的标志色撞车。

想换成自己的图标？
------------------
把 icon-192.png / icon-512.png / icon-1024.png 直接替换掉即可（同尺寸），
不需要改任何代码。想换 vector 版本就同时替换 icon.svg。
