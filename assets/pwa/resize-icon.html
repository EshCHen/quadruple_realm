图标裁剪器

选一张图 → 自动裁成正方形并导出 192 / 512 / 1024 三种尺寸，文件名已取好，直接放进 assets/pwa/ 即可。

点击选择图片 ／ 或把图片拖到这里 支持 PNG · JPG · WebP · SVG（建议原图不小于 512×512）

预览

512
192
64

裁切方式

  1. 下载这 3 个文件（1024 可选，更清晰）
  2. 放进项目的 assets/pwa/ 目录，**文件名不要改**
  3. 刷新站点 → 手机浏览器里「添加到主屏幕」就是这个图标了
所有处理都在你的浏览器里完成，图片不会上传到任何服务器。 如果下载按钮没反应，用任意在线图片工具按同样尺寸导出即可（192×192 / 512×512 / 1024×1024）。
