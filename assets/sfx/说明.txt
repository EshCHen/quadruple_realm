四分境域 · 音效（SFX）说明
=========================================

重要：**这里不需要放任何文件。**

页面的音效是用浏览器内置的 Web Audio 合成的（振荡器 + 噪声 + 滤波器），
不依赖任何音频素材，所以刷新就能听到，也不用担心文件缺失或加载慢。

当前音效表
----------
  悬停档案/域块/按钮   → 短促高频「嗒」（sine 1520Hz，35ms）
  输入文字            → 极轻的按键脉冲（方波，音高有微随机）
  点击档案            → 故障噪声爆（bandpass 1700Hz，140ms）
  翻页                → 上行短音（triangle 520→900Hz）
  通用按钮            → 柔和点击音（sine 700Hz）
  进入档案            → 上行扫频（sawtooth 170→880Hz，0.5s）—— 和「焰火」同步
  操作失败            → 低沉方波（170Hz）

开关
----
顶栏「◈ SFX ON / OFF」可随时开关，**关掉后下次访问会记住**（存本机）。
BGM 与 SFX 是两个独立开关，互不影响。

想自己替换成真实音效素材？
--------------------------
如果你想用采样音（比如机械继电器声、磁带噪声），告诉我，
我把合成器换成「优先读取文件、缺失时回退合成」的双通道：
  悬停 → assets/sfx/hover.mp3
  点击 → assets/sfx/click.mp3
  输入 → assets/sfx/type.mp3
  ……以此类推。

想调音量/音色？
--------------
在 index.html 里搜 `function sfx(kind)`，每一行就是一个音效的
频率、时长、音量参数，改数字即可，不需要懂音频。
总音量在 `sfxCtx()` 里的 `SFX.master.gain.value = 0.5`。
